# Sources for `product-thinking`

The skill's lenses come from 13 open sources by people who built or coached great products. Each entry gives the link, date and the one idea the skill takes; links were checked on 2026-10-17. Where only a secondary page loaded, the entry says so.

## Adding the owner's notes

- Add each note as an entry in `NOTES.md` next to `SKILL.md`: source (who, where, date, link), the lens it belongs to, and the question it adds.
- The skill reads `NOTES.md` on every run and asks each note's question inside its lens, so no edit to `SKILL.md` is needed.
- A note that needs a new lens goes as a new section in `LENSES.md`, with a new tag in its Sources list and a row here.
